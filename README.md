# דאשבורד משאבי אנוש: שלהבת ביטוח

דאשבורד שמרכז במסך אחד את קליטת העובדים, מודעות הדרושים והיציאה לפנסיה בשלהבת ביטוח, חברת ביטוח מומצאת.
כל הנתונים בפרויקט הם נתוני הדגמה.

## יכולות

- **ראש המסך:** 4 מספרים: עובדים בקליטה, מודעות שפורסמו, מועמדים שהוזמנו לראיון, ופרישות ב-6 החודשים הקרובים.
- **קליטת עובדים:** טבלה עם סינון לפי מחלקה וחיפוש לפי שם.
- **מודעות דרושים:** מודעות שפורסמו ומודעות מתוכננות ב-AllJobs, בנפרד.
- **גרף הגיוס:** פניות, הוזמנו לראיון ועברו את הראיון, בסיכום של כל המודעות שפורסמו.
- **יציאה לפנסיה:** רשימה ממוינת מתאריך הפרישה הקרוב לרחוק, עם סינון לפי מחלקה.
- **תאריכים:** מחושבים לפי היום שבו פותחים את הדף, כדי שנתוני ההדגמה לא יתיישנו.
- **טלפון:** בטלפון כל שורה בטבלה מוצגת ככרטיס.

## איך פותחים

הדף הוא אתר סטטי, בלי התקנות. אפשר לפתוח את `index.html` בדפדפן.
