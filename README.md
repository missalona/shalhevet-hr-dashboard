# דאשבורד משאבי אנוש: שלהבת ביטוח

דאשבורד שמרכז במסך אחד את קליטת העובדים, מודעות הדרושים והיציאה לפנסיה בשלהבת ביטוח, חברת ביטוח מומצאת.
כל הנתונים בפרויקט הם נתוני הדגמה.

## יכולות

- **תפריט צד:** קישורים לסקירה, לקליטה, לגיוס ולפרישה. הקישור של החלק שמוצג מודגש.
- **ראש התוכן:** ברכה לפי השעה והתאריך של היום.
- **סקירה:** 4 מספרים: עובדים בקליטה, מודעות שפורסמו, מועמדים שהוזמנו לראיון, ופרישות ב-6 החודשים הקרובים, עם שורת הסבר לכל אחד.
- **קליטת עובדים:** טבלה עם ראשי תיבות, סטטוס, סינון לפי מחלקה וחיפוש לפי שם, ולצידה גרף עוגה לפי מחלקה.
- **גיוס:** גרף בצורת משפך עם אחוזי מעבר, מודעות מתוכננות, וטבלת המודעות שפורסמו ב-AllJobs.
- **יציאה לפנסיה:** רשימה ממוינת מתאריך הפרישה הקרוב לרחוק, עם תגית לפרישה בתוך 6 חודשים וסינון לפי מחלקה.
- **תאריכים:** מחושבים לפי היום שבו פותחים את הדף, כדי שנתוני ההדגמה לא יתיישנו.
- **טלפון:** תפריט הצד הופך לפס עליון, וכל שורה בטבלה מוצגת ככרטיס.

## איך פותחים

- **באינטרנט:** https://missalona.github.io/shalhevet-hr-dashboard/ (מתפרסם מ-`main` דרך GitHub Pages).
- **במחשב:** הדף הוא אתר סטטי, בלי התקנות. אפשר לפתוח את `index.html` בדפדפן.
